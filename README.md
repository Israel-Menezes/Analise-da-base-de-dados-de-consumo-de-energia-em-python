# Analise-da-base-de-dados-de-consumo-de-energia-em-python
Desafio 2, curso Ciência de Dados, Trilhas Inova III. Nesse repositório, uma tabela de consumo de energia .csv foi acessada, manipulada e analisada em Phyton, através das bibliotecas NumPy e Pandas, sendo o meio para definirmos conclusões estatísticas e respondermos os questionamentos propostos em relação dados da tabela.
